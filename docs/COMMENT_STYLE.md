# 中文代码注释规范

## 基本原则

1. 注释说明“为什么”和接口约束，避免逐字复述代码。
2. 模块名、信号名、协议名和数学符号保留英文，说明文字使用简体中文。
3. 不在源码中保留调试过程、版本回退过程或无法验证的结论。
4. 修改逻辑时同步更新相邻注释；过期注释视为缺陷。

## Verilog

手写 RTL 文件使用统一文件头：

```verilog
// =============================================================================
// 文件名称：example.v
// 主要模块：example
// 功能说明：说明该模块在数据通路中的职责。
// 维护说明：修改接口或时序时，请同步更新本文件注释和上层例化。
// =============================================================================
```

时序说明应明确时钟域、复位极性、有效电平和数据延迟。厂商生成 IP 的版权与许可注释必须原样保留。

## Python

- 模块开头使用 docstring 说明用途、输入输出和依赖硬件。
- 类与公开方法使用 docstring 说明职责；复杂分支在代码前说明设计原因。
- 常量按网络、图像和运行时状态分组，单位写入名称或注释。
