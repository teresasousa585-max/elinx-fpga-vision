# 系统架构与协议

## 数据通路

```text
OV5640 摄像头
      │ RGB565
      ▼
采集与颜色转换 ──► 算法选择器 ──► SDRAM 帧缓存 ──► HDMI
                         │
                         └────────► UDP 图传 ──► PyQt6 上位机

PyQt6 上位机 ──串口控制帧──► FPGA 算法命令解析器
```

## 串口控制协议

上位机以 `1,000,000 baud` 打开串口，每次发送固定四字节命令：

| 字节 | 含义 | 取值 |
| --- | --- | --- |
| 0 | 帧头 | `0xAA` |
| 1 | 主模式 | 算法类别 |
| 2 | 子模式 | 类别内选项 |
| 3 | 帧尾 | `0x55` |

模式映射以 `host/main.py` 的 `algo_config` 为唯一维护入口，FPGA 端由 `uart_cmd_parser.v` 解析。

## UDP 图传协议

- 上位机监听 UDP 端口 `8080`。
- 图像尺寸为 `1024 × 600`。
- 每像素为 16 位 RGB565，大端字节序。
- 发送端使用源端口 `8191` 标记新帧起点。
- 切换算法时，上位机清空缓存，并等待下一个新帧标记重新同步。

当前协议没有序号、校验和或重传机制，适用于受控局域网内的低延迟演示。若用于复杂网络环境，建议增加帧号、分片序号、有效载荷长度和 CRC。

## 两套 FPGA 工程

`base` 工程侧重基础图像处理与网络输出，包含颜色转换、几何变换、直方图、形态学、Sobel、HDR 和双边滤波等模块。

`enhancement` 工程侧重引导滤波、暗光增强和磨皮美颜，复用摄像头、SDRAM、HDMI、串口等基础模块。
